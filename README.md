# Hettich · Полезные материалы

Закрытый файлообменник для сотрудников: видео, презентации, документы, картинки, чертежи и любые другие файлы. Их можно смотреть прямо в браузере, скачивать по одному или всё сразу архивом ZIP / RAR / 7z. Вход только по логину и паролю, которые выдаёт администратор.

## Запуск на этом компьютере

Дважды щёлкните `Запустить.bat` или выполните:

```
python server.py
```

Затем откройте http://127.0.0.1:8765. Логин и временный пароль главного администратора лежат в `ДОСТУП_АДМИНА.txt`. При первом входе сайт попросит сменить пароль, после этого файл можно удалить.

Понадобится Python 3.9 или новее. Ничего устанавливать не нужно: используется только стандартная библиотека.

## Запуск в Docker

```
docker compose up -d --build
```

Сайт откроется на http://localhost:8765, контейнер называется `hettich-materials` и сам перезапускается вместе с Docker. Папки `files/`, `archives/`, `assets/` и `data/` подключаются томами, поэтому загруженные через сайт файлы и база сотрудников хранятся в папке проекта и переживают пересборку. В образе уже есть `bsdtar` и `rar` для архивов 7z и RAR. Пересобирать нужно, только если поменялись `server.py` или `web/`: снова `docker compose up -d --build`.

Полезные команды:
- логи: `docker logs -f hettich-materials`
- остановить: `docker compose down`
- сбросить пароль админа: `docker exec hettich-materials python server.py reset-password admin`

## Как выдать доступ сотруднику

1. Войдите под администратором и откройте раздел **Сотрудники**.
2. Нажмите **Добавить сотрудника** и укажите имя. Логин подставится сам, его можно поправить.
3. Система сама придумает пароль. Отправьте его кнопкой **Telegram** или **Почта**, либо скопируйте текст.
4. При первом входе сотрудник сменит пароль на свой.

Если сотрудник забыл пароль, нажмите 🔑 («Выдать новый пароль»). Кнопкой 🔒 можно временно закрыть доступ.

## Если главный администратор забыл пароль

**Ключ восстановления.** Создайте его заранее:
1. Откройте меню с вашим именем → **Ключ восстановления** (пока ключа нет, сайт напоминает о нём жёлтой полосой).
2. Введите текущий пароль. Сайт покажет ключ вида `HETTICH-XXXXX-XXXXX-XXXXX-XXXXX-XXXXX` и даст скачать файл `Hettich_klyuch_vosstanovleniya_admin.txt`.
3. Храните файл отдельно от пароля: на личной флешке, в сейфе или в менеджере паролей. Не пересылайте его по почте и в мессенджерах.

Если пароль забыт: на странице входа нажмите **«Забыли пароль администратора? Войти по ключу восстановления»**, выберите файл ключа и задайте новый пароль.

- Ключ **одноразовый**: после входа по нему сайт попросит создать новый.
- На сервере хранится только хеш ключа (PBKDF2), поэтому даже с копией базы его не восстановить.
- Создание нового ключа отменяет старый.
- После 10 неудачных попыток вход по ключу блокируется на 15 минут.

**Если нет и ключа.** Пароль сбросит тот, у кого есть доступ к серверу:

```
docker exec hettich-materials python server.py reset-password admin
```

Совет: назначьте второго администратора, тогда он сможет выдать вам новый пароль из раздела «Сотрудники».

## Как добавить материалы

Нажмите чёрную кнопку **Загрузить** в шапке сайта или просто перетащите файлы в окно браузера.

**Кто может загружать.** Администратор — всегда. Сотрудник — если в разделе «Сотрудники» у него включён переключатель **«Загрузка»** (у новых сотрудников он включён по умолчанию). Сотрудник может менять и удалять только файлы, которые загрузил сам, а администратор — любые. Закреплять материалы на главной может только администратор.

 Подходит любой тип файла, один файл может весить до 10 ГБ (это меняется параметром `MAX_UPLOAD_GB`).

- **Раздел определяется сам:** Видео, Презентации, Изображения, Документы, 3D и чертежи, Другое.
- **Обложка тоже.** Для видео это кадр из ролика (плюс длительность и качество), для картинок — миниатюра. Остальным файлам можно поставить обложку вручную.
- **Карандаш ✏** на карточке меняет название, описание, раздел и обложку. Там же материал можно закрепить наверху большой карточкой или удалить.
- **Архивы «Скачать всё»** (ZIP, RAR, 7z) пересобираются сами через несколько секунд после загрузки или удаления.

Можно и просто положить файл в папку `files/`: при следующем открытии страницы он появится в каталоге.

Слайды для онлайн-просмотра презентации лежат в `assets/slides/` (JPG 1280×720), их получают в PowerPoint через «Файл → Экспорт → JPEG».

## Что умеют сотрудники

- искать по названию (клавиша `/`), фильтровать по разделам, сортировать, переключать вид «плитка» или «список»;
- смотреть видео, листать презентации, открывать PDF, текст и картинки прямо в браузере;
- отметить несколько файлов галочками и скачать их одним ZIP;
- копировать ссылку на конкретный файл (🔗). Открыть её смогут только те, у кого есть доступ.

## Демо-версия на GitHub Pages

**https://slavadobro.github.io/hettich/** — тот же сайт, но без сервера: вход по кнопке «как администратор» или «как сотрудник», без пароля. Можно смотреть видео и слайды, загружать файлы и заводить сотрудников. Все данные вымышленные и хранятся только в браузере того, кто смотрит. Материалов компании в демо нет: ролик, картинки, слайды и каталог из `demo/` нарисованы специально.

Чтобы обновить демо после правок, выполните `bash deploy/publish-pages.sh`. Скрипт соберёт демо через `deploy/build-pages.py` и выложит его в ветку `gh-pages`.

## Установка на VDS

Подойдёт VDS на Ubuntu 22.04/24.04 или Debian 12: 1–2 ГБ памяти и диск с запасом под материалы (видео плюс три архива «Скачать всё» занимают примерно вчетверо больше самих файлов). Перед сайтом работает **Caddy**: он сам получает и продлевает бесплатный HTTPS-сертификат.

**1. Домен.** В настройках DNS домена создайте A-запись на IP сервера, например `files.example.ru → 203.0.113.10`. Без домена сайт тоже запустится, но по `http://IP` без шифрования, поэтому так можно только проверить.

**2. Установка** — на сервере под root:

```
curl -fsSL https://raw.githubusercontent.com/SlavaDobro/hettich/main/deploy/install.sh -o install.sh
bash install.sh files.example.ru
```

Скрипт:
- ставит Docker и скачивает код в `/opt/hettich`;
- создаёт `.env` и выдаёт сайту права на папки с данными;
- открывает порты 80/443 и запускает сайт;
- в конце показывает логин и пароль первого администратора.

**3. Перенос ваших материалов и сотрудников** — с этого компьютера, из папки проекта:

```
powershell -ExecutionPolicy Bypass -File deploy\copy-to-vds.ps1 -Server root@203.0.113.10
```

Скрипт копирует видео, презентации, обложки, слайды и фон страницы входа, а базу переносит вместе с сотрудниками, вашим паролем и ключом восстановления. Архивы на сервере соберутся сами. Если переносить не нужно, просто войдите под администратором из шага 2 и загрузите файлы через сайт.

**Обслуживание** (на сервере, в `/opt/hettich`):

| Задача | Команда |
|---|---|
| Обновить сайт из GitHub | `bash install.sh` (повторный запуск ничего не стирает) |
| Логи | `docker compose -f docker-compose.prod.yml logs -f` |
| Перезапуск | `docker compose -f docker-compose.prod.yml restart` |
| Сброс пароля админа | `docker compose -f docker-compose.prod.yml exec app python server.py reset-password admin` |
| Резервная копия | `tar czf /root/hettich-backup.tgz data files assets` |

Настройки лежат в `/opt/hettich/.env` (образец в `.env.example`): домен, размер загрузки, порты.

## Что не хранится в репозитории

Репозиторий публичный, поэтому в нём только код. Вот что исключено через `.gitignore`:
- `data/` — база сотрудников;
- `files/`, `archives/` — материалы и архивы;
- `assets/covers/`, `assets/slides/` — обложки и слайды;
- `web/login-bg.jpg` — фон страницы входа;
- файл с паролем администратора.

При первом запуске сервер сам создаёт пустые папки и главного администратора, а пароль выводит в консоль. Материалы после этого загружаются через сайт кнопкой «Загрузить». Чтобы на странице входа была картинка, положите любую горизонтальную фотографию в `web/login-bg.jpg`.

## Структура

| Путь | Что там |
|---|---|
| `server.py` | Сервер: вход, сессии, сотрудники, раздача файлов |
| `web/` | Страницы: материалы, вход, админка |
| `files/` | Сами материалы (закрыты паролем) |
| `archives/` | Архивы «Скачать всё» |
| `assets/` | Обложки и слайды (закрыты паролем) |
| `data/hettich.db` | База сотрудников и каталог материалов. Пароли хранятся только в виде хеша (PBKDF2). Не удаляйте и не публикуйте этот файл |
| `build-archives.ps1` | Ручная сборка архивов. Больше не нужна, сервер собирает их сам |
| `docker-compose.prod.yml`, `deploy/` | Запуск на VDS: Caddy с HTTPS, скрипт установки, перенос данных |
